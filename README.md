# REPUESTOS MOTOR - Prototipo de catálogo

Abrir la carpeta en Visual Studio Code y ejecutar con **Live Server** (clic derecho en `index.html` > Open with Live Server).

- Productos, precios y disponibilidad: `js/products.js` (también el número de WhatsApp en `STORE_CONFIG`).
- Lógica (filtros, buscador, mensajes de WhatsApp): `js/app.js`. La función `loadProducts()` es el punto donde se conectará una base de datos.
- Estilos: `css/styles.css`. Imágenes: `assets/images/`.
- Los datos son de demostración. Horario y ubicación son de ejemplo.
